# Sertifikat Sabula Sabuli

A certificate generator application for Sabula Sabuli events.

## Files

- `index.html` - Main HTML file
- `style.css` - Stylesheet
- `script.js` - JavaScript logic
- `data.json` - Certificate data
- `logo.png` - Logo image
- `Pakkiok Bunting Na Aru Tubarani.svg` - Background certificate template

## Usage

Open `index.html` in a browser to generate certificates.
